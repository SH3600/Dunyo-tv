+ YouTube'dan avtomatik qo'shish

Kalit olish: Google Cloud Console, yangi loyiha, "YouTube Data API v3" ni yoqing, Credentials bo'limida API key yarating va uni "HTTP referrer" orqali sh3600.github.io saytiga cheklang. Faqat saytga o'rnatish ruxsat etilgan videolar qo'shiladi.

Bu test sahifasi. Havola turlari: .m3u8 (HLS), .mp4/.webm, .mpd (DASH), YouTube (video va pleylist), Vimeo. rtmp/rtsp va DRM bilan himoyalangan oqimlar ochilmaydi. Faqat ko'rishga va namoyish etishga haqli kontentdan foydalaning.
